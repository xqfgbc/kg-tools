# 结构化 Markdown 撰写规范（ppt-extract 第六步）

把一个 PPT 的结构化提取结果（`extraction_raw.txt`）撰写成最终 Markdown 文档。
**这是格式转换 + 忠实翻译，不是总结提炼。**

## 输入与输出

| 项 | 说明 |
|---|---|
| 结构化提取 | `{output_dir}/extraction_raw.txt` —— 每页的形状、坐标、类型、TEXT、TABLE 行 |
| 幻灯片图片 | `{output_dir}/asset/slide_NN.png` —— 图形式页面（架构图、流程图、矩阵）**必须看图**才能还原 |
| OCR（可选） | `{output_dir}/ocr_slide_NN.txt` —— 辅助校验图片内文字 |
| **输出** | `{output_dir}/{name}.md` |

## 铁律

1. **结构化内容原样呈现**：严禁对 PPT 页面中的文本、图表、流程做总结、概括、提炼或改述。
   - **允许**：把 PPT 的英文内容**忠实翻译成中文**（逐句对应，不增删改）
   - **允许**：把复杂图形（流程图、关系图、架构图）转换为**表格或多级列表**
   - **允许**：在表格中保留中英文对照
   - **禁止**：添加 PPT 中不存在的主观评论、推断、解读
   - 专业术语保留英文原文：产品名（Dynatrace、ServiceNow）、技术名（MELT、MCP、RAG）、指标名（MTTR、KPI）
2. **每页必须有**：原始图片引用、≤300 字摘要、≤10 个标签。
3. **摘要与标签不受铁律 1 限制**——它们就是用来概括的。
4. 页面里若确有**空白/无文本**，如实写「（本页无文本，仅图形）」，不要编造。

## 单页模板

```markdown
## Slide N: {页面标题}

![Slide N](asset/slide_NN.png)

> **📝 摘要**: {≤300 字，2-4 句：主题 → 核心论点 → 关键结论}

> **🏷️ 标签**: `标签1` `标签2` …（≤10 个）

{结构化内容：表格 / 多级列表 / 段落，中文}
```

**摘要写法**：不要重复标题，要点明「这张 PPT 想传达什么」。多区域页面要说清区域间关系。
**标签选取**：覆盖领域（如 `AIOps`）、内容类型（如 `蓝图` `路线图` `案例`）、技术方法（如 `RAG` `Ontology`）、阶段层级（如 `Stage0` `Strategic`）。

**标签禁用词**（绝对不要出现在标签里）：`埃森哲` `Accenture` `accenture` `目录` `分隔页` `封面` `附录` `占位页`
> 分隔页/目录页也要有标签，但用**内容性**的标签，例如 `章节页` `导航` `SaaS商用`。

## 文档骨架

```markdown
# {PPT 标题} — PPT 解析文档

> **原始文件**: `{filename}` | **页数**: {N} 页 | **解析方式**: 双通道（LibreOffice→PDF→PNG 150DPI + python-pptx 文本/坐标/形状/表格）+ OCR 辅助验证

## 📋 总体概要

| 项目 | 内容 |
|------|------|
| **摘要** | {≤300 字整体描述：这是什么 + 核心叙事逻辑 + 关键结论} |
| **标签** | `tag1` `tag2` …（≤10 个） |
| **章节结构** | {章节列表} |

---

## 幻灯片目录

| # | 标题 / 章节 | 内容概要 |
|---|------------|----------|
| 1 | … | … |

---

## Slide 1: {标题}
…
```

## 格式约定

| 内容类型 | 呈现方式 |
|---|---|
| 简单列表 | 无序 / 有序列表 |
| 对比关系 | 表格 |
| 层级结构 | 多级列表或嵌套表格 |
| 流程 / 路径 | 表格（含步骤序号、阶段、说明列） |
| 演化 / 递进 | 总表 + 分路径详表 |
| 汇总对比 | 横向对比总表 |
| 分隔页 / 目录页 | 如实标注，可用 `【章节页 N】{名称}` 的标题形式 |

## 阅读图形式页面

`extraction_raw.txt` 里的坐标、形状类型、连接线只给出**骨架**。遇到下列情况**必须读 PNG 看图**：
- 架构图 / 蓝图 / 分层图 / 泳道图
- 矩阵（R/Y/G、2×2 象限）
- 甘特图 / 时间线 / 演进路径
- 任一页形状数 > 30 或含大量 GROUP/LINE

坐标可辅助判断空间关系（x 小=左侧，y 小=顶部）。**同一行/列的文本框按 x/y 排序后才是正确阅读顺序**——XML 声明顺序不可靠。

## 输出质量标准

- [ ] 输出语言为中文（专业术语保留英文）
- [ ] 页数、图片引用数、摘要数、标签数四者与源 PPT 页数一致
- [ ] 所有 `![Slide N](asset/slide_NN.png)` 引用的文件都存在
- [ ] 复杂图形已转为表格或多级列表
- [ ] 表格都标注了列含义
- [ ] 未编造 PPT 中不存在的内容
- [ ] 标签不含禁用词，且每页 ≤10 个、总览 ≤10 个
- [ ] 结构化内容区域无总结提炼（摘要/标签除外）
